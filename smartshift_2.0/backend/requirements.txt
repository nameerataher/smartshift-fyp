#
# weather data (temperature, humidity, wind):
#   - meteostat: free api, pip install meteostat
#     docs: https://dev.meteostat.net/python/
#     usage: from meteostat import Point, Hourly
#
#   - era5 (copernicus): more comprehensive, requires account
#     docs: https://cds.climate.copernicus.eu/
#     usage: climate data store api
#
# surface type data (asphalt, grass, concrete):
#   - openstreetmap: free, query via overpass api
#     example: surface=asphalt, landuse=grass
#     docs: https://wiki.openstreetmap.org/wiki/Key:surface
#
#   - mapbox: tilequery api for land use
#     docs: https://docs.mapbox.com/api/maps/tilequery/
#
# building data (for shadow calculations):
#   - openstreetmap: building footprints and heights
#     tag: building=*, height=*
#
#   - mapbox: 3d buildings in mapbox gl js
