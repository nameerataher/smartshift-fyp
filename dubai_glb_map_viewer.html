This overlays a GLB onto an OSM basemap using ONE anchor (Burj Khalifa @ 25.1972, 55.2744).
To make it exact, set the model anchor point (ax/ay/az) to the Burj base location in your GLB.
How to get ax/ay/az: in Blender select the Burj object and read its Location (or run a tiny script to print it).
